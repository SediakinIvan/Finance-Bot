Результат локальных проверок: 170 Python-тестов прошли, оба Node-набора прошли, strict OpenSpec 14/14, git diff --check без ошибок. Node проверял текущий локальный макрос с отдельно накопленными правками; эти правки в бот-релиз не входят.

Проверены активные/неактивные категории и подкатегории, перенесённая подкатегория и несвязанный отсутствующий снимок. Имена обновляются в существующих индексированных листах, исходные ID, финансовые суммы, даты и исторический родитель сохраняются. Отсутствующие снимки не создаются; ссылки остаются. Предпросмотр не пишет в Google, предупреждение учитывает уникальные листы и сохраняется в приватном плане. Отмена не применяет изменение; восстановленный лист или изменённый индекс делают подтверждение устаревшим. Native-тест partial rename/resume подтверждает прежние суммы архива, сохранение индекса и отсутствие запросов перестройки диаграмм.

Ограничение: живое переименование пользователем не воспроизводилось автономно, чтобы не менять его справочник и историю.
