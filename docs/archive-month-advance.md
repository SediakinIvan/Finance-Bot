# Автоматический следующий месяц

В bound Apps Script **ИФТ-таблицы** откройте `saveMonthlyReport`. В самом конце функции, сразу после строки очистки `identities` и перед `}finally{`, найдите:

```javascript
    cleanExit=true;
    ui.alert('Архив проверен, операции очищены. Задайте следующий месяц в Аналитика!D1.');
```

Замените только эти две строки на:

```javascript
    if(period.month===12)analytic.getRange(1,4,2,1).setValues([[1],[period.year+1]]);
    else analytic.getRange(1,4).setValues([[period.month+1]]);
    cleanExit=true;
    ui.alert('Архив проверен, операции очищены. Аналитика переключена на следующий месяц.');
```

Сохраните Apps Script. Весь макрос заменять не требуется; миграция книги и передеплой бота не нужны. Main и промышленная таблица не обновляются.

После подтверждённой очистки переход работает для всех месяцев: 1→2, …, 10→11, 11→12, 12→1 с увеличением года. Для месяцев 1–11 D2 не записывается. Архив содержит исходный закрытый месяц и прежние суммы. При отказе от замены архива/очистки или ошибке до переключения период остаётся прежним.

Проверено локально: все 12 переходов, неизменность остальных ячеек аналитики, исходный период и суммы архива, отсутствие записи D2 в обычном месяце, отмены и ошибки до перехода. Оба Node-набора, strict OpenSpec и diff --check прошли. Bound Apps Script этой работой автоматически не изменён.
