# Безопасность и данные

## Доступ и изменение данных

- По решению владельца читать можно все данные проекта.
- Изменять финансовые записи можно только после подтверждения пользователя; сохранять существующий сценарий подтверждения в боте.
- Удаление данных из таблицы без подтверждения пользователя запрещено.
- Передача данных разрешена в Telegram и Google Sheets в рамках работы бота. Других разрешённых внешних получателей сейчас нет; расширение списка требует решения владельца безопасности.
