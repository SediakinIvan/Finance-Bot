# Закрытие месяца

Источник: описание владельца и предоставленный им актуальный текст `saveMonthlyReport()` в интервью. Поведение соответствует ранее изученному `data/macros.gs`; макрос не запускался и не изменялся.

## Подтверждённый рабочий порядок

1. В конце месяца владелец записывает последнюю трату этого месяца.
2. Запускает макрос архивации для текущего периода «Аналитика» D1:D2.
3. Макрос сохраняет итоги в «Архив», создаёт снимок аналитики и очищает «Траты».
4. После архивации владелец вручную задаёт новый номер месяца в «Аналитика» D1 для расчёта следующего периода.

- Переключение D1 следует после архивации: макрос использует D1:D2 и для имени архива, и для выбора уже рассчитанных итогов. Сам макрос месяц и год не меняет.
- Автоматические действия выполняются внутри запущенного макроса; запуск по расписанию из рассказа владельца не следует.

## Что сохраняет актуальный макрос

- В сводный лист «Архив» записывает месяц и год, доход, расход, остаток и четырнадцать категорий из фиксированных ячеек аналитики.
- В лист «Архив (<название месяца> <год>)» копирует значения «Аналитика», ширину столбцов и форматирование. Формулы и исходные операции «Траты» в этот снимок не копируются.
- Затем очищает содержимое «Траты» со строки 2 по последнюю заполненную строку и по всем используемым столбцам. Отбора только закрываемого месяца нет.
- Уже существующую сводную запись предлагает перезаписать; отказ завершает функцию.
- Уже существующий лист снимка предлагает заменить; отказ пропускает создание снимка, но не останавливает очистку «Траты».

## Ограничения и расхождения

- Отдельного подтверждения очистки «Траты» нет. Это остаётся расхождением с общим инвариантом владельца о подтверждении удаления; ручной запуск макроса пока не объявлен владельцем исключением из правила.
- Архив содержит итоги и снимок аналитики, но не построчную историю исходных операций. Другие резервные копии не подтверждены.
- Данные операций других месяцев, если они есть в «Траты», также очищаются.
- Операции записи сводки, создания снимка и очистки выполняются последовательно без общей транзакции. Частичное выполнение после ошибки возможно; наличие механизма восстановления не установлено.
- В ветке создания первого сводного архива выражение `getRange(2, 1, lastRow - 1, 1)` может получить ноль строк при одном заголовке. Исполнение этого граничного случая не проверялось.
