# Контекст продукта

- Telegram-бот для упрощения отслеживания личных финансов.
- Сейчас предназначен для личного использования владельцем. Поддержка других пользователей возможна в будущем; это не подтверждённое текущее требование.
- Google Sheets используется как база данных; бот обращается к ней через API.

## Ключевые сценарии

- Записывать траты в таблицу через удобный интерфейс бота.
- Получать аналитику по тратам за текущий месяц.
- Просматривать последние операции.

## Критичные инварианты

- Бот не должен удалять данные из таблицы без подтверждения пользователя. Любое удаление требует подтверждения.

## Ограничения и технический долг

- Обновление категорий затруднено: от них зависят разрозненные процессы — формулы аналитики в таблицах, архивирование месяцев и кнопки бота. Изменение категорий требует согласованных правок во всех этих местах.
