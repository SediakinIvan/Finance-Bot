# Purpose
Текущее разграничение доступа по finance_bot/config.py, finance_bot/bot.py и main.py; это описание механизма, а не подтверждение ИБ.

## Requirements
### Requirement: Доступ только по Telegram ID в личном чате
Бот MUST обслуживать настроенные числовые Telegram ID только в private chat.
#### Scenario: Текстовая команда
- **WHEN** регистрируются команды и текстовые обработчики
- **THEN** применяются фильтры разрешённых ID и личного чата.
#### Scenario: Callback
- **WHEN** обрабатывается callback
- **THEN** код проверяет ID отправителя и тип чата; неавторизованный callback отклоняется.

### Requirement: Отдельная таблица для пользователя
Конфигурация MUST сопоставлять пользователя с его таблицей.
#### Scenario: Основной и дополнительные пользователи
- **WHEN** приложение запускается
- **THEN** основной ID получает GOOGLE_SHEET_ID, дополнительные задаются TELEGRAM_USER_SHEETS как TELEGRAM_ID:SPREADSHEET_ID через запятую; создаётся отдельный адаптер для каждого.
#### Scenario: Неоднозначная конфигурация
- **WHEN** ID пользователя повторяется, одна таблица назначена нескольким пользователям или запись имеет неверный формат
- **THEN** загрузка конфигурации отклоняется.

## Ограничения
- Поддержка нескольких пользователей уже есть в коде; фактическое число подключённых пользователей не проверялось.
- Используется общий настроенный Google service account; изоляция по маршрутизации бота не означает отдельные Google credentials для пользователей.
