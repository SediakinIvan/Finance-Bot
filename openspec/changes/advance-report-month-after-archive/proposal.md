# Proposal

## Why

После закрытия месяца владелец вручную меняет «Аналитика»!D1, а при переходе декабря в январь также D2. Макрос должен выполнять только этот шаг автоматически после успешного завершения существующего сценария.

## What Changes

- После сохранения и проверки архива, подтверждённой очистки операций и завершения существующей очистки служебных снимков переключать D1 на следующий месяц относительно закрытого периода.
- При декабре записывать D1=1 и D2=закрытый год+1. Для остальных месяцев D2 не записывать.
- При отмене замены архива, отказе от очистки или ошибке до переключения сохранять исходный период.
- В существующем финальном уведомлении заменить просьбу вручную задать месяц сообщением об автоматическом переключении; новых диалогов не добавлять.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `workbook-versions`: автоматический переход периода после полного успешного закрытия месяца v2-архиватором.

## Impact

Только небольшой завершающий участок `saveMonthlyReport` в `data/macros.gs`, проверки в `tests/test_archive_script.cjs` и инструкция установки этой правки. Не менять остальные алгоритмы, формулы, категории, диаграммы, архивные колонки, подтверждения, блокировки, восстановление или Python-код бота. Существующие незакоммиченные правки сохранить отдельно, без рефакторинга. Main, промышленный бот, рабочая книга и legacy-макрос вне области изменения. Bound Apps Script автоматически из Git не обновляется.
