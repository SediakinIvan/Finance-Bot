# Spec Delta

## Purpose

Главное меню даёт пользователю доступ к действиям бота, позволяя освобождать экран сворачиванием панели и снова открывать кнопки при необходимости.

## ADDED Requirements

### Requirement: Сворачиваемое главное меню
Главное меню SHALL допускать скрытие средствами клиента Telegram и SHALL NOT запрашивать постоянное отображение при скрытии обычной клавиатуры.

#### Scenario: Скрытие обычной клавиатуры
- **GIVEN** пользователь получил обновлённое меню бота в клиенте Telegram с поддержкой сворачивания reply-клавиатуры
- **WHEN** пользователь переключается с меню на обычную клавиатуру и смахивает её вниз для скрытия
- **THEN** панель скрывается без немедленного автоматического открытия меню бота.

#### Scenario: Сворачивание меню
- **WHEN** пользователь скрывает главное меню штатным действием клиента Telegram
- **THEN** меню допускает сворачивание и не требует оставаться раскрытым.

### Requirement: Повторный доступ к меню
Скрытое меню SHALL оставаться доступным через штатную иконку reply-клавиатуры Telegram, а команда `/help` SHALL отправлять актуальное сворачиваемое меню.

#### Scenario: Открытие скрытого меню
- **WHEN** пользователь нажимает штатную иконку reply-клавиатуры после сворачивания меню
- **THEN** доступны кнопки главного меню.

#### Scenario: Обновление ранее отправленного меню
- **GIVEN** в чате осталась клавиатура предыдущей версии бота
- **WHEN** авторизованный пользователь отправляет `/help` после установки исправления
- **THEN** бот отправляет обновлённое сворачиваемое меню.

### Requirement: Совместимость действий меню
Меню SHALL сохранять существующие десять кнопок, их подписи, порядок и распределение по пяти рядам; нажатия SHALL запускать существующие действия без добавления автоскрытия после выбора.

#### Scenario: Состав меню
- **WHEN** пользователь открывает меню
- **THEN** показаны пары «Добавить транзакцию (сегодня)» / «Добавить транзакцию (вчера)», «Добавить транзакцию» / «Последние 10 операций», «Удалить последнюю» / «Выбрать для удаления», «Аналитика» / «Аналитика по категориям», «Версия» / «Отменить текущую запись» в указанном порядке.

#### Scenario: Существующий сценарий ввода
- **WHEN** пользователь выбирает добавление операции из повторно открытого меню
- **THEN** запускается прежний диалог с обязательным подтверждением перед записью; скрытие меню само по себе не записывает и не удаляет финансовые данные.
