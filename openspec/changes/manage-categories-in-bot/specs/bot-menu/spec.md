# Spec Delta

## MODIFIED Requirements

### Requirement: Совместимость действий меню
Меню SHALL сохранять существующие десять кнопок, их подписи, порядок и распределение по первым пяти рядам; нажатия SHALL запускать существующие действия без добавления автоскрытия после выбора. Кнопка «Категории» SHALL добавляться отдельным шестым рядом и открывать управление справочником.

#### Scenario: Состав меню
- **WHEN** пользователь открывает меню
- **THEN** показаны пары «Добавить транзакцию (сегодня)» / «Добавить транзакцию (вчера)», «Добавить транзакцию» / «Последние 10 операций», «Удалить последнюю» / «Выбрать для удаления», «Аналитика» / «Аналитика по категориям», «Версия» / «Отменить текущую запись» в указанном порядке, а ниже — «Категории».

#### Scenario: Существующий сценарий ввода
- **WHEN** пользователь выбирает добавление операции из повторно открытого меню
- **THEN** запускается прежний диалог с обязательным подтверждением перед записью; скрытие меню само по себе не записывает и не удаляет финансовые данные.

#### Scenario: Управление справочником
- **WHEN** авторизованный пользователь нажимает «Категории» или отправляет `/categories` в личном чате
- **THEN** открывается список категорий с действиями и отменой; reply-меню сохраняет возможность сворачивания.
