# Spec Delta

## ADDED Requirements

### Requirement: Кнопка архивации месяца на ИФТ
При включённой ИФТ-конфигурации меню SHALL добавлять кнопку «Архивация месяца» отдельным рядом после «Категории»; команда `/archive_month` SHALL открывать тот же диалог. Существующие кнопки, их порядок и сворачивание MUST сохраняться. В ПРОМ новая кнопка и выполнение команды MUST отсутствовать.

#### Scenario: Обновление меню ИФТ
- **WHEN** владелец отправляет `/help` ИФТ-боту после подключения функции
- **THEN** приходит сворачиваемое меню с кнопкой «Архивация месяца», нажатие начинает предпросмотр без архивации и очистки.

#### Scenario: Обычный ввод
- **WHEN** пользователь нажимает кнопку архивации во время ввода траты
- **THEN** текст кнопки не сохраняется как значение траты; неподтверждённый ввод отменяется с объяснением, начинается отдельный диалог архивации.

#### Scenario: Рабочее окружение
- **WHEN** открыт ПРОМ-бот или в него вручную отправлена команда архивации
- **THEN** новая операция не запускается; текущие production-меню, книга, макрос и runtime не изменяются этим выпуском.
