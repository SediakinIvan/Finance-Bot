# Proposal

## Why

Владелец хочет закрывать месяц прямо в ИФТ-боте, запуская существующий Apps Script архиватор вместо перехода в таблицу. Архивирование, очистка и переключение периода должны сохранить нынешние правила и подтверждения.

## What Changes

- Только ИФТ получает кнопку «Архивация месяца» и команду `/archive_month`.
- Бот показывает выбранный в D1/D2 месяц и подтверждение запуска; если архив существует — явно предлагает его замену. После проверки сохранённого архива отдельно запрашивает подтверждение очистки трат.
- Вызывается общий код существующего макроса в Apps Script через защищённый web app. Логика расчётов и формирования архива не дублируется на Python; текущий запуск из меню Sheets сохраняется.
- Повтор кнопки, перезапуск и потеря HTTP-ответа не закрывают месяц повторно: запрос имеет постоянный ID, сохраняемый статус и проверку результата.
- ПРОМ-бот, его таблица и установленный макрос не изменяются; текущая приёмка production-архивации в конце месяца остаётся открытой.

## Capabilities

### New Capabilities

- `bot-month-archiving`: подтверждаемое закрытие выбранного месяца из Telegram с выполнением существующего Apps Script и наблюдаемым результатом.

### Modified Capabilities

- `bot-menu`: условная кнопка архивации только в ИФТ без изменения существующих действий и сворачивания меню.

## Impact

`finance_bot/bot.py`, `config.py`, новый клиент вызова Apps Script/диалог архивации, `data/macros.gs` с выделением общего ядра и web app adapter; test env/compose/workflow для приватных URL и ключа, Python/Node-тесты и инструкция установки ИФТ Apps Script. Production Compose, runtime, книга и bound Script остаются прежними.

Техническое ограничение: нынешний saveMonthlyReport вызывает getUi()/alert, поэтому удалённый вход должен использовать то же ядро без интерфейса Sheets. Нынешний service account не поддерживается scripts.run; выбран подписанный HTTP-вызов web app, исполняемого владельцем и жёстко ограниченного ИФТ-книгой. Развёртывание web app и установка скрипта владельцем — явная часть подключения, существующий Docker deploy их не выполняет.
