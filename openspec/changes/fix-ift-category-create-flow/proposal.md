# Proposal

## Why

На ИФТ создание «Одежда» после ввода подкатегорий не даёт понятного результата. Read-only воспроизведение на ИФТ-книге выявило `An indexed archive sheet is missing`: создание без необходимости обходит все архивные подписи. Закрытие диалога затем заменяет ошибку общим сообщением, скрывая причину отказа.

## What Changes

- Исключить обход/изменение исторических архивных подписей из create/add/move/deactivate; эти действия не переименовывают старые архивы.
- Сохранить строгую проверку архивных ссылок и прежние гарантии при rename; не удалять индекс, не восстанавливать и не создавать отсутствующие архивы автоматически.
- Сделать понятным исход диалога: список подкатегорий ведёт к preview либо видимой ошибке, закрытие не затирает ошибку/успех, успешное применение требует подтверждения.
- Добавить регрессионные тесты с отсутствующим архивом и маршрутизацией настоящего ConversationHandler.
- Выпустить только test-тег из feature/manage-categories после проверок. Main, production Compose/workflow/token/таблица и работающий промышленный бот не меняются.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `workbook-versions`: границы использования архивного индекса для v2 и наблюдаемый результат диалога при ошибке/отмене предпросмотра.

## Impact

`finance_bot/category_changes.py`, `finance_bot/category_management.py`, `finance_bot/category_ui.py`, регрессионные тесты; существующий Test stand workflow. Новые зависимости, миграция и изменение Apps Script не требуются. ИФТ-книга читается для воспроизведения; её финансовые записи, отсутствующие архивы и исторический индекс не исправляются автономно. Полная приёмка исходной feature остаётся отдельной задачей.
