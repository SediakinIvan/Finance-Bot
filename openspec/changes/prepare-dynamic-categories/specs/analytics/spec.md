# Spec Delta

## MODIFIED Requirements

### Requirement: Источник месячных итогов
Бот MUST читать рассчитанные значения листа аналитики, не пересчитывая их из операций; расчёты таблицы MUST учитывать устойчивые связи операций.
#### Scenario: Период отчёта
- **WHEN** пользователь запрашивает аналитику
- **THEN** период берётся из «Аналитика» D1:D2; совпадение с текущей календарной датой не проверяется.
#### Scenario: Сводка
- **WHEN** аналитика прочитана
- **THEN** доступны расходы, доходы, разница доходов и расходов выбранного месяца и динамическая таблица категорий с постоянными ID.
#### Scenario: Некорректные данные
- **WHEN** обязательные итоги, период или связи отсутствуют либо не разбираются
- **THEN** возвращается ошибка, а не выдуманные нулевые итоги.
#### Scenario: Нулевые расходы
- **WHEN** в месяце нет расходов
- **THEN** общие расходы и доли категорий равны нулю без ошибок деления; отсутствие обязательных данных не подменяется нулём.

### Requirement: Аналитика подкатегорий
Бот MUST показывать динамическую детализацию категорий по связям, сохранённым в операциях, включая историческое использование неактивных сущностей.
#### Scenario: Выбор категории
- **WHEN** пользователь открывает аналитику по категориям
- **THEN** доступны все активные категории расходов и неактивные категории с операциями выбранного периода; фиксированного списка из четырёх категорий нет.
#### Scenario: Чтение блока
- **WHEN** пользователь выбирает категорию
- **THEN** детализация сопоставляется по ID категории и подкатегорий и отображает текущие названия; расположение блоков не задаётся вручную для каждой категории.
#### Scenario: Одинаковые названия
- **WHEN** разные категории содержат одноимённые подкатегории
- **THEN** их суммы не объединяются.
#### Scenario: Историческое использование после переноса
- **WHEN** в выбранном периоде подкатегория использована до и после переноса
- **THEN** каждая категория показывает только операции с сохранённым в них ID этой категории.
#### Scenario: Изменение списка после показа кнопок
- **WHEN** справочник изменился после открытия выбора аналитики
- **THEN** старая кнопка не перенаправляется на другую категорию из-за изменения индексов; выбор разрешается по устойчивой идентичности либо отклоняется как устаревший.
